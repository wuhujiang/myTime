# myTime 绿色版使用说明

## 开始使用

将 ZIP 完整解压到可写目录，打开 `myTime` 文件夹，双击 `myTime.exe` 即可运行。请勿直接在压缩包中运行。

适用于 Windows，建议 Windows 10 / 11，需要系统自带的 .NET Framework 4.x。无需安装，不会创建快捷方式或设置开机启动。

默认显示洛杉矶和北京的时间，包含秒数，窗口保持置顶且不显示任务栏按钮。每个城市名称下方显示当地的月、日和星期（例如“11月3日 周一”），与该行时间使用同一个时区，分别跨日更新，不受电脑本地时区设置影响。当前固定使用紧凑视图，设置入口暂未开放。

## 操作

- 拖动标题区域移动窗口。
- 点击 `-` 隐藏到托盘。
- 双击托盘图标，或右键选择“显示”，恢复窗口。
- 点击 `x`，或右键托盘选择“退出”，退出程序。
- `Ctrl+Alt+M` 隐藏或恢复窗口。
- `Ctrl+Alt+Q` 退出程序。

快捷键被其他程序占用时，可通过窗口按钮或托盘菜单操作。

## 配置与更新

程序会在自身目录自动生成配置：

- `settings.txt`：窗口位置。
- `clocks.tsv`：时钟列表。
- `migrations.txt`：配置迁移记录。

移动时请移动整个文件夹。更新时先退出程序，再覆盖 `myTime.exe` 和本说明，保留配置文件。卸载时退出程序并删除整个文件夹。

程序不要求账号、不上传数据，也不会自动联网更新。新版本请从下载本程序的 GitHub 仓库 Releases 获取，下载 `myTime-版本号-windows.zip`，不要下载源码包。
