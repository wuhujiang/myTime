# myTime Android

`two` 分支的 Android 版本是一个主屏幕时钟与天气小组件，同时显示中国咸阳和阿尔及利亚廷杜夫的当地日期、星期、时间及天气。咸阳使用中国时区（Asia/Shanghai），廷杜夫使用阿尔及利亚时区（Africa/Algiers）。无需账号、API Key 或定位权限；天气查询需要联网。

## 构建

用 Android Studio 打开本目录 `android/`，等待 Gradle 同步完成后运行 `app` 配置即可。也可以在已安装 Android SDK 和 Gradle 8.2 的环境中运行：

```bash
gradle --no-daemon :app:assembleDebug
gradle --no-daemon :app:assembleRelease
```

APK 输出在 `app/build/outputs/apk/`，当前工作流提供使用 Android 调试签名、可以直接安装的测试包：

- `two-0.1.0-debug.apk`

正式发布构建需要配置自己的 Android 签名密钥；未签名的 `release` APK 不能直接安装。

## 添加小组件

1. 安装 APK。
2. 长按 Android 手机主屏幕，选择“小组件”。
3. 找到 `myTime 时钟`，拖到主屏幕。
4. 调整小组件尺寸即可。

小组件默认请求 3 列 × 1 行桌面网格，允许缩小到 40dp 高；实际占用的网格数及外边距由桌面启动器决定。黑色圆角背景铺满组件实际区域，每组第一行左侧显示地名、右侧显示天气与摄氏温度；下一行左侧显示月日和星期、右侧显示时间。地名分别显示“咸阳”和“廷杜夫”。两组之间留 4dp 间距，上下内边距为 4dp，整体垂直居中。底部的“天气：Open-Meteo”可点击查看数据提供方。

Android 8.0 及以上按每项文字实际可用的空间分别调整字号，地名、天气、日期和时间的字号上限为 20sp、14sp、16sp、30sp；各项保持单行显示，不按桌面报告的最小高度统一缩小。Android 6.0 / 7.x 使用固定字号。

如果从旧版升级后仍保留较大的占位，可以长按组件拖动上、下边缘缩小；若桌面继续沿用旧尺寸，请移除组件后重新添加。

系统负责在后台唤醒时钟更新；不同手机系统可能会对更新时间做少量延迟。

## 天气与网络

天气来自 [Open-Meteo](https://open-meteo.com/) 的当前天气接口，按固定城市中心坐标查询：咸阳约为 34.3296°N、108.7088°E，廷杜夫约为 27.6711°N、8.1474°W。显示天气状况和四舍五入的摄氏温度，数据为天气模型估算，可能与当地气象站实测不同。

- 首次添加组件后，系统在网络可用时安排查询；以后每约 30 分钟尝试更新。安卓省电策略可能延迟更新。
- 首次尚未成功联网时显示“天气待更新”；请求失败保留上次结果，失败后的重试至少间隔 5 分钟。数据超过两小时在天气末尾加 `*`，表示缓存较旧。
- 时钟不依赖天气接口；断网仍显示本机换算的日期和时间。天气请求使用 HTTPS，只发送固定城市坐标；服务提供方也能获知正常网络连接的 IP 地址，不读取设备定位。
- 联网、网络状态及用于重启后恢复天气任务的权限均为普通权限，无需弹窗授权。移除全部组件后会取消后台更新任务。

天气数据按 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 使用，已将 WMO 天气代码翻译为中文并取整温度。Open-Meteo [免费接口条款](https://open-meteo.com/en/terms)适用于非商业用途，限制每分钟 600 次、每小时 5,000 次、每天 10,000 次请求；商业使用需另行配置合适的服务方案。
